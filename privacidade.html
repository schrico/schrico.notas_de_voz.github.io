Política de privacidade

Última atualização: 20 de novembro de 2026.

Que dados a aplicação trata

  • As gravações de áudio que o utilizador faz. Ficam guardadas só no telemóvel até o utilizador as enviar.
  • O endereço de email da conta Google ligada, usado apenas para mostrar no ecrã qual é a conta ligada.

Uso dos dados do Google

A aplicação usa a API do Google Drive com o âmbito drive.file, que só dá acesso aos ficheiros e pastas criados pela própria aplicação. Usa esse acesso apenas para criar a pasta Notas de Voz/Inbox e enviar para lá as gravações, quando o utilizador o pede. Não lê, altera nem apaga outros ficheiros do Drive.

O uso e a transferência de informação recebida das APIs Google respeitam a Google API Services User Data Policy, incluindo os requisitos de Limited Use.

Partilha

Os dados não são enviados para nenhum servidor do programador nem partilhados com terceiros. A aplicação não tem publicidade, análise de utilização nem rastreio. As gravações vão diretamente do telemóvel para o Google Drive do utilizador.

Guarda e eliminação

Depois de confirmado o envio, a gravação é apagada do telemóvel. As gravações no Drive ficam sob o controlo do utilizador, que as pode apagar quando quiser. O utilizador pode desligar o Google Drive na aplicação ("Desligar") ou retirar o acesso em myaccount.google.com/permissions. Desinstalar a aplicação apaga todos os dados guardados no telemóvel.

Contacto

Para questões sobre esta política, abre um pedido em github.com/schrico/schrico.notas_de_voz.github.io/issues.
